# PIE-SEMI-EVAL

PIE-SEMI-EVAL es una aplicación web para organizar y evaluar seminarios de avance de tesis de la Maestría en Ciencias y Doctorado en Ingeniería Eléctrica. Permite administrar periodos, estudiantes, evaluadores y asignaciones, así como capturar evaluaciones y consultar reportes.
